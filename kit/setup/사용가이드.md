# Lively AI 도우미 설치 & 사용 가이드 (비개발자용)

이 가이드대로 하면 새 노트북에서 **조직 전용 AI 도우미(Claude Code)**를 쓸 수 있습니다.
조직 맥락(우리 일하는 방식·도메인·프로젝트)을 이미 아는 상태로 켜집니다.

> 어려운 거 없습니다. **명령 한 줄(또는 스크립트 한 번) 실행 → 끝.** 5~10분 걸려요.
> git clone·레포 주소 같은 건 필요 없습니다 — 게이트웨이에서 설치 묶음을 바로 받아옵니다.

---

## 1. 설치 (한 번만)

관리자에게 **설치 명령 한 줄**(본인 토큰이 박힌)을 받는 게 가장 쉽습니다. 관리 페이지 `[설치]` 탭에서 본인 토큰을 발급하면 그 한 줄이 그대로 나옵니다.

### Windows

방법 A — **명령 붙여넣기(권장):**
1. 시작 메뉴에서 **PowerShell** 을 엽니다.
2. 관리자가 준(또는 `[설치]` 탭에서 복사한) **PowerShell 한 줄 명령**을 붙여넣고 엔터. (Claude 설치 → 묶음 다운로드 → MCP 연결 → user-level 설치가 자동으로 진행됩니다.)

방법 B — **스크립트 파일 실행:**
1. 관리자가 준 **`setup-windows.ps1`** 파일을 바탕화면 등에 둡니다.
2. 그 파일을 **마우스 우클릭 → "PowerShell에서 실행"**.
   - "토큰을 붙여넣으세요"가 나오면 관리자가 준 **토큰**을 붙여넣고 엔터.
   - 게이트웨이 주소는 `LIVELY_GATEWAY` 환경변수나 `-McpUrl` 로 줍니다(관리자 안내).
   - (파란 경고창이 뜨면 "추가 정보 → 실행". 회사 배포 스크립트라 안전합니다.)
3. **"끝!"** 메시지가 나오면 완료.

### Mac

터미널에서 관리자가 준 **한 줄**을 붙여넣고 엔터하면 끝입니다(토큰이 박혀 있음). 형태는 이렇습니다:

```
T=<내토큰>; curl -fsSL -H "Authorization: Bearer $T" "<게이트웨이>/install" -o /tmp/lv.tgz && mkdir -p /tmp/lv && tar -xzf /tmp/lv.tgz -C /tmp/lv && LIVELY_TOKEN=$T bash /tmp/lv/setup/setup-mac.sh
```

> 이미 설치돼 있으면 알아서 **최신 묶음으로 업데이트만** 합니다. 그냥 다시 실행해도 안전해요.

---

## 2. 켜기

1. **아무 폴더**(자기 코드 레포 포함)에서 `claude` 를 켜면 됩니다 — user-level 설치라 실행 위치는 상관없습니다(Windows·Mac 동일).
   - Windows: 폴더 주소창에 `powershell` 치고 엔터 → 까만 창에 `claude` 엔터.
   - Mac: 터미널에서 `claude`.
2. 처음이면 **브라우저 로그인 창**이 떠요 → **회사 계정으로 로그인**.
3. "이 폴더를 신뢰하시겠습니까(trust)" 류 확인이 뜨면 **승인**(회사 배포 설정이라 안전). → 끝.

이제 대화하면 됩니다. (훅 특성상 **다음 세션부터** 시작 현황 주입·리플렉스가 적용됩니다.)

> 세션 시작 시 팀 현황(검토 대기 건수 등)이 자동으로 뜹니다 — **Mac·Windows 모두 동작**합니다.

---

## 3. 어떻게 쓰나요?

그냥 **한국어로 물어보면** 됩니다. 예시:

- "우리 커머스 도메인에 어떤 데이터가 있는지 알려줘"
- "이번 분기 진행 중인 프로젝트 목록 정리해줘"
- "brands 테이블에서 채널 타입별 브랜드 수 세줘"
- "결제 관련 도메인 부채 뭐가 있어?"

도우미가 회사 맥락(도메인 맵)과 실제 데이터를 직접 조회해서 답합니다.
끝낼 때는 까만 창에 `exit` 치거나 창을 닫으면 됩니다.

---

## 4. 최신 내용으로 업데이트

회사 맥락(일하는 방식·도메인 설명 등)은 **매 세션 자동 갱신**이라 보통 따로 할 게 없습니다.
훅/설정이 바뀌었을 때만 업데이트하세요 — **설치 명령(또는 스크립트)을 한 번 더 실행**하면 됩니다(설치된 토큰을 읽어 최신 묶음을 받습니다).

- Windows: `setup/update-windows.ps1` 실행(또는 `[설치]` 탭의 업데이트 명령 붙여넣기).
- Mac: `[설치]` 탭의 업데이트 명령 붙여넣기.

---

## 5. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `claude` 쳤는데 "명령을 찾을 수 없음" | 터미널/PowerShell 창을 **새로 열고** 다시 `claude`. 그래도 안 되면 설치를 재실행. |
| 설치 중 "토큰이 비어 있음" | 관리자가 발급한 본인 토큰을 붙여넣어야 합니다(관리 페이지 `[설치]` 탭에서 본인이 발급 가능). |
| 설치 중 "게이트웨이 주소 없음 / 다운로드 실패" | 게이트웨이 주소(`LIVELY_GATEWAY`, 예 `http://<host>:8080/mcp`)가 필요합니다. 관리자에게 문의. |
| 도메인/DB 질문에 "연결 안 됨" | MCP 미연결. `claude mcp list` 로 `lively` 확인 → 없으면 설치 재실행. |
| 로그인이 안 됨 | 회사 계정인지 확인. 그래도 안 되면 관리자 문의. |

막히면 캡처해서 조직 관리자에게 보내주세요.

---

## 6. 제거하기

Lively 설정을 머신에서 **완전히 떼어내고 싶을 때**(이직·정리 등).

- **Mac:** 관리 페이지 `[설치]` 탭의 **제거 명령**을 붙여넣어 실행(설치된 토큰을 자동으로 읽음). 또는 설치 묶음을 푼 폴더에서 `bash setup/uninstall-mac.sh`.
- **Windows:** `setup/uninstall-windows.ps1` 실행(또는 `[설치]` 탭의 제거 명령).

동작:
- 무엇이 지워질지 먼저 **미리보기**를 보여주고, **정말 지울지 한 번 물어봅니다**(y 눌러야 진행).
- 떼어내는 것: `claude`/`codex` 의 lively 훅(커스텀 훅 런너 포함)·MCP 등록(게이트웨이 + 조직이 추가한 MCP 서버) · 자동승인(auto-approve) 설정 · 셸 토큰 설정 · `~/.lively` 폴더.
- **건드리지 않는 것**: 여러분의 다른 설정(tmux 알림·codex 로그인/모델·셸 별칭 등)은 그대로 둡니다.
- `~/.lively` 는 바로 영구삭제가 아니라 **`~/.lively.removed-<날짜>` 로 옮겨**둡니다(되돌릴 수 있음 — 안에 설치 전 원본 백업도 함께 보관). 완전 정리 전까지는 두세요.

옵션(Mac uninstall-mac.sh): `--dry-run`(미리보기만) · `--purge`(완전 삭제) · `--harness claude|codex`(한 하네스만) · `--yes`(확인 생략).

> **임시로 끄고 싶을 뿐**이라면 제거하지 말고 `LIVELY_OFF=1` 환경변수를 쓰세요 — 설치는 그대로 두고 잠깐만 조용해집니다(incognito). 제거(uninstall)는 영구적입니다.
> 토큰 회수는 관리자 몫입니다 — 이직 시엔 관리자에게도 알려 서버에서 접속 권한을 끊어달라고 하세요([온보딩.md](온보딩.md) 오프보딩).

### (관리자용 메모)
멤버 설치는 git clone 이 아니라 게이트웨이 **`/install` 토큰게이트 번들**로 단일화돼 있습니다(관리 UI `[설치]`/`[구성원 추가]` 탭이 토큰 박힌 한 줄 명령을 발급). 스크립트로 줄 경우 `setup-windows.ps1` 은 다음만 필요합니다:
- `McpUrl` — MCP 게이트웨이 주소(예: `http://<host>:8080/mcp`). 파라미터 또는 `LIVELY_GATEWAY` 환경변수. 설치 번들도 여기서 받습니다(`.../install`).
- `McpToken` — 사용자별 토큰(비우면 실행 중 입력). 사람마다 다른 토큰 권장.
- `McpLabel` — MCP 등록 라벨(기본 `lively`). 단일 출처는 `context-ontology/scripts/register-clients.sh` — 변경은 거기 먼저.

게이트웨이(`context-ontology`)는 사내망에서 reachable 해야 하고, 클라이언트가 외부면 노출/터널 필요. 멤버 추가·신원(이메일·Discord·ClickUp 연결)은 관리 UI `[구성원]` 탭에서 — 상세는 [온보딩.md](온보딩.md).
