# 라이블리 연결 설정

이 플러그인은 **라이블리 게이트웨이**(조직의 맥락 스토어)에 붙어야 동작한다. 게이트웨이가 없으면 이 플러그인이 하는 일도 없다 — 먼저 무엇을 가졌는지 확인한다.

## 1. 어떤 게이트웨이인지 먼저 확인

| 상황 | 게이트웨이 주소 |
|---|---|
| 회사가 **매니지드**(app.lvly.io)를 쓴다 | 워크스페이스 주소 그대로 (`https://<워크스페이스>.app.lvly.io`) |
| 회사가 **셀프호스팅**한다 | 관리자가 알려준 주소 (`https://lively.회사도메인`) |
| 아직 아무것도 없다 | 게이트웨이를 먼저 띄워야 한다 → https://github.com/livewithlively/lively |

## 2. 값 두 개를 넣는다

플러그인을 활성화하면 두 값을 묻는다. 나중에 바꾸려면 `/plugin` → 이 플러그인 → 설정.

- **게이트웨이 주소** — 위에서 확인한 주소(`/mcp` 는 붙이지 않는다, 자동으로 붙는다).
- **접속 토큰** — 게이트웨이 관리 화면에서 발급한 개인 토큰(`lvk_` 로 시작). 키체인에 저장되며 `settings.json` 에는 남지 않는다.

여기까지 하면 **MCP 툴**이 붙는다. 챗 표면(웹·데스크톱 Chat 탭)은 이걸로 끝이다.

## 2-1. 훅까지 쓰려면 한 번 더 로그인 (Claude Code·Cowork)

조직 맥락 자동주입·조직 스킬 배포·거버넌스 훅은 **훅**이 하는 일이고, 훅은 토큰을 파일에서 읽는다.

```bash
node "$CLAUDE_PLUGIN_ROOT/bin/login.mjs"
```

승인 주소와 코드가 뜨고 브라우저가 열린다. 승인하면 토큰이 `~/.lively/token`(권한 600)에 저장된다.
**새 세션을 열어야** 조직 맥락·스킬이 함께 온다.

> **왜 두 번인가** — 플러그인 설정의 비밀 값은 키체인에 저장되는데 그 값이 **훅 프로세스에는 전달되지 않는다**(실측). 그래서 MCP 헤더용 토큰(설정)과 훅용 토큰(파일)의 경로가 갈린다.

## 3. 연결 확인

새 세션을 열고 아래를 확인한다.

1. **MCP 툴이 보이는가** — `mcp__lively__whoami` 를 호출해 본다. 내 이름·소속·권한이 나오면 연결된 것이다.
2. **조직 맥락이 주입되는가** — 세션 시작 시 조직 카테고리 목록과 WIKI 인덱스가 보이면 SessionStart 훅이 도는 것이다.
3. **조직 스킬이 내려오는가** — 게이트웨이에 조직 스킬이 등록돼 있으면 첫 세션 이후 자동으로 받아진다(이 플러그인이 동봉한 스킬과 별개).

## 4. 안 될 때

| 증상 | 원인·조치 |
|---|---|
| MCP 툴이 아예 없다 | 주소 오타(스킴 `https://` 포함했는지). `/plugin` 설정에서 주소를 다시 확인 |
| 401 이 난다 | 로그인을 아직 안 했거나 토큰이 회수됐다 → 위 2번의 `login.mjs` 를 다시 실행 |
| "이미 키트가 설치한 토큰이 있습니다" | 이 컴퓨터엔 키트가 깔려 있다 — 플러그인 대신 키트를 쓰거나(권장), 옮기려면 키트를 먼저 제거 |
| 연결은 되는데 조직 맥락이 안 보인다 | 게이트웨이는 살아 있으나 SessionStart 훅이 안 도는 경우. `/hooks` 로 배선을 확인하고, 사내망이면 그 주소에 이 머신이 닿는지 확인 |
| 회사 네트워크에서만 안 된다 | 셀프호스팅 게이트웨이가 사내망에만 있으면 외부에서 못 닿는다. VPN 또는 관리자에게 공개 노출 여부 확인 |

## ⚠ 키트(`curl … | sh`)와 함께 쓰지 않는다

라이블리에는 설치 경로가 둘 있다. **둘 중 하나만 쓴다.**

- **플러그인**(이 경로) — 마켓플레이스에서 설치. 훅·MCP 배선이 플러그인 안에 있다.
- **키트** — 게이트웨이가 주는 `curl -fsSL <게이트웨이>/cli | sh` 한 줄. 훅을 `~/.lively/hooks/` 에 깔고 `~/.claude/settings.json` 을 머지한다.

둘 다 깔면 같은 훅이 두 번 돈다(중복 주입·중복 보고). 이미 키트를 설치했다면 이 플러그인은 필요 없다. 굳이 옮기려면 `~/.lively/uninstall` 로 키트를 먼저 걷어낸다.
