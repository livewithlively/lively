## 연결 — 사람 몫은 [허용] 한 번

1. 무엇을 모을지 먼저 정한다: **드라이브만** / **드라이브와 지메일** (지메일은 개인 메일이라 아래 «모을 범위»의 경고를 먼저 한다).
2. `org_google_collect_connect { services:["drive"] }`(지메일도 모으면 `["drive","gmail"]`) → `authorization_url`. 그 링크를 주고 말한다: «이 링크를 열고 구글 계정을 고른 뒤 [허용]을 눌러 주세요.» 구글 검증 전 앱이면 «확인되지 않은 앱» 화면에서 [고급] → [(앱 이름)(으)로 이동]을 누르면 된다고 함께 말한다. 링크는 10분 동안만 쓸 수 있다.
   - 라이블리 계정과 **같은 이메일의 구글 계정**으로 연결하게 한다 — 메일함 이름이 라이블리 계정 이메일로 붙는다.
   - `me_oauth_connect { server:"google" }` 로 연결하면 지메일 권한이 빠진다 — 수집에는 위 도구를 쓴다.
3. 사람이 «했어요»라고 하면 `org_google_collect` 로 `connected` 가 생겼는지, 원한 서비스의 `scope_ok=true` 인지 확인한다.
- 연결만으로는 수집이 켜지지 않는다 — 아래 «모을 범위»에서 켠다.
- 나중에 지메일을 더하려면 `org_google_collect_connect { services:["gmail"] }` 로 **권한을 넓힌다**(이미 가진 권한은 유지된다). 이미 `scope_ok=true` 인 서비스로 다시 부르면 구글 화면만 한 바퀴 돌고 아무것도 안 바뀐다.

## 모을 범위

- ⚠ **지메일**: 모은 메일은 이 워크스페이스 구성원 **모두에게 보인다**(공개범위 규칙을 따로 정하지 않았다면). 개인 메일이 섞이므로 반드시 먼저 말하고 동의를 받는다. 업무 메일만 모으려면 검색식으로 좁힌다(아래).
- 켜기: `org_google_collect_set { enabled:true, services:["drive"] }` (지메일도 켜려면 `["drive","gmail"]`).
  - ⚠ `services` 는 **켜 둘 전체 목록**이다. 빠진 서비스는 꺼진다 — 지메일이 켜져 있는데 `["drive"]` 만 보내면 지메일 수집이 꺼진다.
  - ⚠ 켤 때마다 수집이 **부른 사람의 구글 연결**로 바뀐다. `collectors[]` 의 수집기가 다른 사람 연결로 돌고 있으면(`org_collectors` 의 `config.token_source`) 먼저 말하고 동의를 받는다 — 지메일이면 모으는 메일함 자체가 바뀐다.
  - 동의하지 않은 서비스는 켜지지 않고 `skipped` 로 돌아온다 — 그때는 «연결»의 권한 넓히기를 한다.
- 좁히기(켠 뒤, `org_collectors` 에서 그 수집기 id 를 찾아):
  - 드라이브 폴더: `org_collector_upsert { id:<gdrive 수집기 id>, config:{ folders:"<폴더 id, 쉼표 구분>" } }`. 폴더 id 는 드라이브 폴더 주소 `…/folders/<id>` 의 끝부분이다. **고른 폴더 바로 안의 파일만** 가져오고 하위 폴더는 들어가지 않는다. 비우면 드라이브 전체(공유 드라이브 포함)다.
  - 지메일 검색식: `org_collector_upsert { id:<gmail 수집기 id>, config:{ query:"<지메일 검색식>" } }` — 예: `label:업무 newer_than:180d`. 비우면 메일함 전체다.

## 확인

- 켜면 첫 수집이 바로 시작된다(처음엔 전체를 읽어 오래 걸릴 수 있다). 1~2분 뒤 `org_collectors` 에서 preset `gdrive`·`gmail` 의 `last_run` 을 본다. 들어온 자료: `source_list { kind:"drive_file", limit:5 }` · `source_list { kind:"email", limit:5 }`.
- 드라이브·지메일 정리 규칙(증류기)은 자동으로 생기지 않는다 — 공통 규칙 «연결 뒤» 3을 꼭 한다.

## 함정

- 연결한 사람이 구글 연결을 끊거나 워크스페이스를 떠나면 수집이 멈춘다. 다른 사람이 연결하고 «모을 범위»의 켜기를 다시 하면 이어받는다(그 사람 계정으로 바뀐다).
- 드라이브 목록은 한 번에 2만 개까지 본다. 그보다 많으면 폴더로 좁힌다.
