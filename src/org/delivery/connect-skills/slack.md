## 연결 — 사람 몫은 [허용] 한 번

1. `me_oauth_connect { server:"slack" }` 를 부른다. `authorization_url` 이 오면 그 링크를 주고 말한다: «이 링크를 열고, 연결할 슬랙 워크스페이스를 고른 뒤 [허용]을 눌러 주세요. 화면에 나오는 권한은 모두 허용해야 연결돼요.» 링크는 10분 동안만 쓸 수 있다 — 늦었으면 다시 부른다.
   - `authorized:true` 가 오면 이미 연결돼 있다 — «모을 채널»로 간다.
   - 화면으로 하고 싶어 하면: `org_connect_status` 의 `connect_url`(슬랙 화면) ▸ «내 계정으로 직접 사용» 스위치.
2. 사람이 «했어요»라고 하면 `org_slack_collect` 로 `me_connected=true` 를 확인한다. 같은 동의로 라이블리 봇도 그 슬랙 워크스페이스에 설치된다 — `bot.available=true` 면 설치된 것이다.
   - 봇이 없는데 사람은 예전에 연결해 둔 상태라면, 다시 연결해도 동의 화면이 뜨지 않는다. 사람에게 말하고 `me_oauth_disconnect { server:"slack" }` 로 **내 연결만** 지운 뒤 1을 다시 한다(이미 모은 자료·다른 사람 연결은 지워지지 않는다). 이번엔 봇이 함께 설치된다.

## 모을 채널

- 슬랙 수집은 두 갈래다: **봇을 초대한 채널**(비공개 포함)과 **공개 채널 검색**(수집을 켠 사람의 계정으로). DM·그룹 DM 은 어떤 설정으로도 모으지 않는다.
- 공개 채널 목록: `org_collect_scope_options { system:"slack" }` — 채널 **이름**이 온다. 비공개 채널은 목록에 없으니 사람이 이름을 말해야 한다.
- 이름과 성격을 보고 모을 채널을 제안한다. 알림 봇만 오가는 채널, 잡담, 오래 조용한 채널은 빼자고 제안하고 이유를 한 줄씩 단다. 비우면 볼 수 있는 채널 전부다.
- 확인을 받으면 `org_slack_collect_set { enabled:true, channels:"<채널 이름들, 공백 구분>" }`. 처음에 거슬러 읽을 날짜를 정했으면 `backfill_since:"YYYY-MM-DD"` 도 함께(비우면 활동이 있는 과거 전체).
  - ⚠ `channels` 에는 채널 **이름**을 넣는다. id 를 넣으면 공개 채널 검색이 0건이 된다.
  - ⚠ `_set {enabled:true}` 는 수집을 **부른 사람의 연결**로 바꾼다. `org_slack_collect` 의 `search.member` 가 이 사람이 아니면 먼저 말한다: «지금은 ○○님 연결로 모으고 있어요. 채널을 바꾸면 이제부터 당신 연결로 모아요.» 동의를 받은 뒤에만 부른다.
- **봇 초대** — 봇은 초대받은 채널만 읽는다. 모을 채널마다 사람이 그 채널에서 `/invite` 를 입력하고 라이블리 앱을 고르게 안내한다(한 채널씩). 초대하지 않은 기밀 채널은 읽히지 않는다는 것도 말한다.
- 모은 자료는 이 워크스페이스 구성원 모두에게 보인다(공개범위 규칙을 따로 정하지 않았다면). 비공개 채널을 모을 때는 이 사실을 먼저 말하고 동의를 받는다.

## 확인

- 켜면 첫 수집이 바로 시작된다. 1~2분 뒤 `org_collectors` 에서 preset `slack` 의 두 줄(`lively-search` 공개 채널 검색 · `lively-bot` 봇 초대 채널)의 `last_run` 을 본다.
- `lively-search` 가 권한 문제로 실패하면(오류에 «권한»·«scope»·«다시 연결»이 보이면): 공개 채널 **검색** 수집이 이 앱 권한으로는 되지 않는 것이다. 다시 연결해도 고쳐지지 않는다. «봇을 초대한 채널은 그대로 모아요»라고 사실대로 말하고, 모을 공개 채널에도 봇을 초대하게 안내한다. 실패가 계속 쌓이지 않게 사람에게 말한 뒤 `org_collector_upsert { id:<lively-search 의 id>, enabled:false }` 로 검색 수집만 끈다.
- `lively-bot` 이 초대된 채널이 없다는 이유로 실패하면, 위 «봇 초대»가 아직이다.
- 들어온 자료: `source_list { system:"slack", limit:5 }`.
- 슬랙 자료를 지식으로 정리하는 규칙(증류기)은 자동으로 생기지 않는다 — 공통 규칙 «연결 뒤» 3을 꼭 한다.

## 함정

- 수집을 켠 사람이 연결을 끊거나 워크스페이스를 떠나면 공개 채널 검색 수집이 멈춘다(봇 수집은 계속 돈다). 그때는 다른 사람이 연결하고 «모을 채널»을 다시 하면 이어받는다.
- 토큰을 붙여 넣는 방식(`slack_user_token`)으로 연결한 사람은 수집 기준으로는 «미연결»이다 — 수집에는 위 «연결»의 [허용] 연결이 필요하다.
